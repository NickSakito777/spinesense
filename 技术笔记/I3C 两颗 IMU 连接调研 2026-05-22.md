# I3C 两颗 IMU 连接调研 2026-05-22

> 承接 [[STEVAL-MKI248KA 商业版IMU规格]] 和 [[I3C 多颗 IMU bring-up 实操 2026-05-22]]。本页只处理 N=2 起步测试，不直接跳到 5 颗 garment 总线。

## 结论

两颗 STEVAL-MKI248KA 可以共用同一条 I3C SCL/SDA 总线。第一轮不要用 ENTDAA，走 **SETDASA**；两颗的 `TA0/SA0/SDO` 分别固定成不同电平：

| IMU | TA0/SA0/SDO | 静态地址 | SETDASA 后动态地址建议 |
|---|---|---:|---:|
| IMU_A | GND | `0x6A` | `0x32` |
| IMU_B | 3V3/VDDIO | `0x6B` | `0x33` |

这比“两个都 TA0=3V3 再靠 ENTDAA 找设备”稳。原因是 ISM6HG256X datasheet 明确支持 `SETDASA 0x87`，用 `0x6A/0x6B` 静态地址分配动态地址；而项目旧记录里已经记录过同型号多颗 ENTDAA 容易卡在 PID 仲裁。

## 两颗接线

| Nucleo-U385RG-Q | IMU_A DIL24 adapter | IMU_B DIL24 adapter | 说明 |
|---|---|---|---|
| `3V3` | `JP1 pin 1 VDDIO` + `JP1 pin 2 VDD` | 同左 | 两颗并联供电 |
| `GND` | `JP2 pin 13 GND` | 同左 | 必须共地 |
| `D15 / PB13` | `JP2 pin 20 SCL` | 同左 | I3C2_SCL，总线并联 |
| `D14 / PB14` | `JP2 pin 21 SDA` | 同左 | I3C2_SDA，总线并联 |
| `GND` 或 MCU GPIO 低电平 | `JP2 pin 22 SDO-SAO / TA0` | - | IMU_A 静态地址 `0x6A` |
| `3V3` 或 MCU GPIO 高电平 | - | `JP2 pin 22 SDO-SAO / TA0` | IMU_B 静态地址 `0x6B` |
| 不接 | `JP2 pin 14 INT1`, `pin 15 INT2` | 同左 | 第一轮读数据不需要中断 |
| 不接 | `JP2 pin 19 CS` | 同左 | CS 默认上拉，I2C/I3C 模式可用；异常时再手动拉到 3V3 |

## 测试顺序

1. 单颗 IMU_A：TA0=GND，确认 `0x6A -> 0x32`，读 `WHO_AM_I`。
2. 单颗 IMU_B：TA0=3V3，确认 `0x6B -> 0x33`，读 `WHO_AM_I`。
3. 两颗同时上电并联：先给 `0x6A` 发 SETDASA 到 `0x32`，再给 `0x6B` 发 SETDASA 到 `0x33`。
4. 轮询读取 `0x32` 和 `0x33` 的加速度/陀螺仪 XYZ，Serial Monitor 打两行或一行 CSV。

## 上拉电阻判断

STEVAL-MKI248KA adapter 本身没有给 SCL/SDA 放强上拉。第一轮可以先用 STM32U385 的 I3C dedicated internal pull-up；如果两颗并联后出现 NACK、偶发读失败、Serial 数据断续，就在总线靠近 Nucleo 端临时加：

| 线 | 电阻 |
|---|---|
| SCL -> 3V3 | `2.2 kΩ` 或 `1.5 kΩ` |
| SDA -> 3V3 | `2.2 kΩ` 或 `1.5 kΩ` |

不要一开始焊死，先用面包板或可拆线验证。

## 扩到 3 颗以上时的变化

两颗可以靠 TA0 一高一低区分，因为静态地址刚好有两个。3 颗以上没有第三个静态地址，所以要进入多颗方案：

- 每颗 TA0 独立回 MCU GPIO，按顺序让目标 IMU 落在 `0x6A` 或 `0x6B` 再 SETDASA；
- 或者每颗 VDD/VDDIO 做独立电源开关，逐颗上电、逐颗分配动态地址；
- 最终 5 颗 garment 总线不应该把所有 TA0 短到同一个 3V3/GND。

## 依据

- ST data brief: STEVAL-MKI248KA 是 DIL24 adapter kit，提供完整 ISM6HG256X pinout。
- ST schematic: `JP1 pin 1/2 = VDDIO/VDD`，`JP2 pin 13/20/21/22 = GND/SCL/SDA/SDO-SAO`。
- ST AN6353: `TA0` 是 I2C device address LSB，也是 MIPI I3C static address LSB；`SCL/SDA` 是 I2C/MIPI I3C 主接口。
- ISM6HG256X datasheet: I3C target 支持 `ENTDAA` 和 `SETDASA 0x87`；`SETDASA` 通过 `0x6B/0x6A` 静态地址分配动态地址。
